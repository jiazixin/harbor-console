# 控制台规范对齐的技术决定

状态：采用。适用范围：当前未上线的 Go + React 控制台。

## 查询、路由与状态

TanStack Query 负责读取、请求取消、有限重试、缓存和写入后的查询失效。React Router 负责多页面 Hash 路由；URL 保存筛选与分页。版本由 `web/package-lock.json` 固定。二者替代手工请求状态和刷新计数器，没有保留旧实现。会话、主题、语言、全局提示分别由 `app/` 下的 Context Provider 管理。

这些库承担独立职责：Query 不管理可分享的导航状态，Router 不维护服务端数据。保留必要的稳定回调和路由对象引用，移除未经测量、也不用于稳定依赖的 `useMemo`。

## 不可信 JSON

采用 Zod 4.6.7（MIT）校验用户浏览器存储及 Harbor 在字段中嵌入的 JSON，例如预热策略、公告和任务参数。它补足 TypeScript 编译期类型无法验证运行期输入的缺口；同仓库 API 的类型转换只留在请求包装。安装时核对 npm 元数据和 [Zod 官方说明](https://zod.dev/basics)，并运行生产依赖漏洞审计。通过 `z.config({ jitless: true })` 关闭动态代码生成及其能力探测，以遵守不含 unsafe-eval 的 CSP。不要把解析失败当成有效的空业务数据；可丢弃的个人显示偏好有明确默认值。

## Harbor 边界

控制台自有会话、实例、错误和分页协议遵循 `docs/API.md`。`/api/operations/` 中的资源对象及嵌入字段由 Harbor v2.15 的契约定义：保留其字段、枚举、日期与单位，网关逐项校验允许的写入字段。它们是外部系统的原始数据，不是旧控制台的兼容接口。浏览器不直接访问 Harbor，不跟随携带凭据的重定向，也不显示上游内部错误文本。

Harbor Basic Auth / CLI Secret 必须在转发时恢复，因此在会话存活期间保留于服务端内存；不能将它们单向哈希后再完成 Basic Auth。它们不落盘、不回传、不记录日志，持有类型的字符串输出被屏蔽。控制台自己的会话令牌只存 SHA-256 摘要。登录幂等回复通过每进程秘密与随机种子重新派生 Cookie，不缓存明文令牌；退出和过期始终优先于重放。

## 样式与测试

组件独有规则就近放入 CSS Module，共用控件规则放在 `components/shared-ui.module.css`，领域共用规则留在领域模块。全局只保留设计变量、元素基础样式和关键帧。级联层次显式声明，异步页面加载顺序不决定优先级。跨组件选择器显式引用稳定的作用域类名，全局动画用 `global(...)` 引用。

Harbor Label 的颜色是经过六位十六进制校验的业务数据，用 SVG paint 属性展示；设计配色仍只在 `styles/tokens.css` 定义。CSS 类型从相邻文件生成：`node scripts/generate-css-types.mjs`。测试读取当前样式的级联层并保留尺寸与布局约束，浏览器矩阵检查真实几何、焦点与动画。
