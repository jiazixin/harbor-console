# 控制台整体检查与体验改进

**目标：** 保留现有功能和工作区修改，统一视觉基础、动效和键盘交互，整理长期文档。

**架构：** 继续使用 Go 嵌入 React 静态产物。优先修改共享组件与样式源，不引入 UI 框架或重复页面覆盖层。

**技术栈：** Go、React、TypeScript、CSS、Vitest、Playwright。

## 实施顺序

1. 基线：检查源码、现有未提交修改，运行 `npm run check`、`npm test`、`go test ./...`，截图查看概览和项目页。
2. 视觉：在 `styles.css` 定义圆角、层次和动效 token；更新现有 CSS 的控件、面板、弹窗和文字对比度；修正远程仓库导航命名。
3. 动效：重整 `motion-system.css`，清除失效的旧 DOM 选择器和重复子动画；统一 hover、页面、内容、弹层和加载旋转；刷新按钮使用真实 busy 状态。
4. 交互：新增共享 modal 生命周期，应用到 `ControlDialog` 和全局搜索；覆盖焦点循环、返回、Escape、嵌套选择器和滚动锁。修复提交成功后仍挂载的弹窗一直 busy 的问题。
5. 文档：将迁移历史与当前设计分开，精简设计、开发和验收文档；补充可维护的 UI 规范和本轮验证证据。
6. 验证：运行完整检查、Go race/vet、组件与跨浏览器路由矩阵；补充真实浏览器的动效、键盘、暗色与移动端测试；构建嵌入产物，检查 diff。

## 验收边界

- 中文/英文、桌面/窄屏、亮色/暗色均无页面横向溢出。
- 路由仅一个进入动画 owner；筛选/分页/刷新不重挂载页面；减少动态效果时禁用位移动画。
- 弹窗焦点不逃逸，关闭恢复触发器，菜单 Escape 不关闭父弹窗。
- 自动测试与 demo 证据单独记录，未连接真实 Harbor 的行为不声明已验收。
